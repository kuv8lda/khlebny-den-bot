# Telegram UX

## Тексты и кнопки

- Заголовок сообщает состояние. Следующие строки дают факты и действие. Основной экран занимает 2–4 логические строки; Telegram переносит их по ширине телефона.
- В заголовке используем один эмодзи или ✓. Кнопки называют действие: «Подтвердить заказ», «Посмотреть состав». Постоянная клавиатура содержит разделы «Меню», «Корзина», «Мои заказы».
- В пустой корзине предлагаем выбрать выпечку. При ошибке объясняем, какие данные сохранили и как повторить действие.
- Предупреждаем о демо на старте, при подтверждении и после создания заказа. В условиях приватности сохраняем ограничения удаления данных.
- Показываем обычный текст без HTML и MarkdownV2. При отображении имени и комментария заменяем пробельные последовательности одним пробелом; в заказе храним исходный текст.

Примеры:

```text
🛒 Корзина пуста
Откройте меню и добавьте выпечку.
```

Кнопка: «Выбрать выпечку».

```text
✏️ Имя · шаг 1 из 3
Напишите имя: от 1 до 40 символов. Можно вымышленное.
Отменить оформление: /cancel
```

```text
⚠️ Заказ №12 сохранён
Панель не подтвердила отправку. Товары уже в заказе, корзина пуста.
Повторите отправку кнопкой ниже или из /orders. Дубля не будет.
```

Кнопка: «Повторить отправку».

## Сценарии

| Раздел | Поведение |
|---|---|
| Меню | Пять товаров на странице. Нажатие добавляет одну штуку и показывает «Добавлено: …». Лимит: 20 штук одного товара. |
| Корзина | Две позиции на странице, кнопки − / + / ✕. Итог включает всю корзину. После удаления позиции бот ограничивает номер страницы доступным диапазоном. |
| Оформление | Имя → комментарий или «Без комментария» → подтверждение. При ошибке ввода пользователь остаётся на текущем шаге. |
| Состав на подтверждении | По две позиции на странице, возврат к подтверждению. Просмотр не меняет снимок заказа. Токен старого оформления не открывает новое. |
| Отмена | Кнопка и `/cancel` очищают незавершённое оформление, сохраняя корзину. После подтверждения отмена не отзывает созданный заказ и не прерывает отправку. |
| Повтор отправки | Бот отправляет сохранённый заказ с прежним `Idempotency-Key`. Кнопка доступна после сбоя и в карточке заказа. |
| Мои заказы | Последние пять заказов. В карточке доступны состав, имя, комментарий, дата UTC и статус. Чужие и удалённые заказы недоступны. |
| Владелец | Карточка по две строки данных на странице, проверка прав при смене статуса и листании. При конфликте бот сообщает об ошибке и обновляет статус, если панель его передала. При сбое оставляет кнопки для повтора. |
| Приватность | `/privacy` и результаты `/forget` разбиты по три предложения на страницу без потери текста. Листание не удаляет данные. |

## Ответ на нажатия и сетевые операции

Обработчик отвечает на callback до запроса панели и перерисовки сообщения. Перед ответом он проверяет токен оформления, права доступа и локальные данные. При изменении количества он сохраняет корзину до ответа.

Во время подтверждения заказа, повтора, смены статуса и анонимизации бот показывает typing через `ChatActionSender`. Обработчик ждёт сетевую операцию; при выходе из контекста индикатор прекращается, в том числе после ошибки. Отдельной задачи отправки вне учёта завершения работы нет.

Изоляция FSM ставит действия одного пользователя в очередь. Повторное нажатие может ждать блокировку занятого обработчика. Тесты проверяют порядок callback-ответа и сетевых операций, но не гарантируют ответ за секунду в Telegram.

## Код и проверки

- `khlebny_bot/ui.py`: диапазон страниц и отображение текста одной строкой.
- `khlebny_bot/handlers.py`: меню и корзина.
- `khlebny_bot/checkout.py`: FSM, снимок заказа, подтверждение и повтор отправки.
- `khlebny_bot/owner.py`: карточки владельца и смена статусов.
- `khlebny_bot/privacy.py`: страницы условий и результатов удаления.
- `khlebny_bot/texts.py`: сообщения и названия кнопок.

```bash
source .venv/bin/activate
python -m pytest -q tests/test_ux.py tests/test_checkout_ack.py tests/test_order_retry_ack.py tests/test_ux_documents.py
```

Тесты проверяют сохранность текста при листании, порядок ответов, завершение typing и доступ к данным. Для измерения задержки и проверки отображения на телефоне нужна живая проверка Telegram.
