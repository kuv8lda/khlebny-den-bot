# khlebny-den-bot

Демо Telegram-бот пекарни «Хлебный день» на aiogram 3 (long polling).
Пекарня вымышленная, заказы демонстрационные, реальных платежей нет.
Позже бот будет работать с панелью orders-admin-panel через `/api/integrations/*`.

## Запуск

Нужен Python 3.11+ и токен от @BotFather.

```bash
python3 -m venv .venv && source .venv/bin/activate && pip install -e ".[dev]"
cp .env.example .env   # вписать BOT_TOKEN, затем: python -m bot.main
```

Системный `pip` на Debian/Ubuntu ставить пакеты не даёт (PEP 668), поэтому нужен venv.

Через Docker: `docker compose up --build`.

## Настройки

Переменные окружения (или `.env`, он в `.gitignore`):

- `BOT_TOKEN` — токен бота, обязателен.
- `LOG_LEVEL` — уровень логов, по умолчанию `INFO`.
- `FSM_DB_PATH` — путь к SQLite-файлу с состоянием, по умолчанию `data/fsm.sqlite3`.

## Команды бота

- `/start` — приветствие и кнопки «Меню», «Корзина», «Мои заказы».
- `/menu` — 9 позиций, нажатие добавляет позицию в корзину.
- `/cart` — состав, количество (1–20), итог; кнопки «−», «+», «✕» и «Очистить корзину».
- `/cancel` — сбросить текущее состояние (корзина сохраняется).
- `/help` — справка.

«Мои заказы» пока отвечает заглушкой.

## Проверки

```bash
ruff check .
pytest -q
```

Тесты работают на моках, без сети.

## Структура

- `bot/main.py` — запуск, подключение хранилища и роутера.
- `bot/handlers.py` — обработчики и клавиатуры.
- `bot/cart.py` — логика корзины и формат цен.
- `bot/catalog.py` — каталог (пока хардкод, формат `[{id, name, price_cents}]`).
- `bot/texts.py` — все тексты бота.
- `bot/storage.py` — FSM-хранилище на SQLite, переживает перезапуск.
- `bot/config.py` — настройки.
- `tests/` — тесты.
- `DECISIONS.md` — отклонения от ТЗ.
