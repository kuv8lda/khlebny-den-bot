# Отклонения от ТЗ

- Точка входа: bot/main.py, запуск через `python -m bot.main` (а не корневой main.py).
- Конфиг на этапе 0 содержит только BOT_TOKEN и LOG_LEVEL; параметры панели добавим вместе с интеграцией.
- SQLite-хранилище FSM не входит в этап 0, добавится вместе с первым сценарием на FSM.

# Отклонения и допущения

- Цены в `bot/catalog.py` — временные значения
- `/cancel` сбрасывает состояние FSM, но не корзину; очистка корзины — отдельная кнопка.
- Количество меняется кнопками «−»/«+» в диапазоне 1–20, а не вводом числа.
- «Мои заказы» на этапе 1 отвечает заглушкой.
- FSM-хранилище SQLite написано на stdlib `sqlite3` через `asyncio.to_thread`, без aiosqlite.
- `httpx` и `respx` не подключены: сети на этапе 1 нет, добавим на этапе 3.
