# Отклонения от ТЗ

- Точка входа: bot/main.py, запуск через `python -m bot.main` (а не корневой main.py).
- Конфиг на этапе 0 содержит только BOT_TOKEN и LOG_LEVEL; параметры панели добавим вместе с интеграцией.
- SQLite-хранилище FSM не входит в этап 0, добавится вместе с первым сценарием на FSM.

# Отклонения и допущения

- Цены в catalog.py — временные значения: список цен демо-каталога панели мне не передан. Сверить с панелью до приёмки.
- /cancel сбрасывает состояние FSM, но не корзину (корзина лежит в данных FSM; очистка — отдельная кнопка).
- Количество меняется кнопками «−»/«+» (диапазон 1–20), а не вводом числа.
- Кнопка «Мои заказы» на этапе 1 отвечает заглушкой, истории заказов ещё нет.
- SQLite-хранилище FSM написано на stdlib sqlite3 (вызовы через asyncio.to_thread), без aiosqlite, чтобы не добавлять зависимость.
- respx и httpx в зависимости не включены: сети на этапе 1 нет, добавим на этапе 3.
